# 设置

从账号菜单打开设置。账号资料需要联网；主题和编辑器工具栏偏好保存在当前设备。

## 昵称

在线修改昵称并保存。网络不可用时，昵称无法提交。

## 修改密码

修改密码时需要输入当前密码和新密码。成功后，当前会话会结束；其他设备上的会话也需要重新登录。

## 外观主题

主题可选跟随系统、浅色或深色。默认跟随系统。主题偏好保存在当前设备，不会同步到其他设备。

## 固定编辑器工具栏

固定工具栏默认关闭。开启后，只在宽度至少 768px 的布局中显示固定编辑器工具栏；触摸工具栏仍按触摸交互使用。此偏好按当前账号、工作区和设备分别保存。

## 软件说明与更新

“软件说明”显示版本信息，并提供检查更新和查看更新日志的入口。

## MCP

“设置 → MCP”会显示当前运行环境的 MCP 地址，并提供复制按钮。你可以在这里创建独立 Access Token、查看创建时间与最近使用时间，以及单独撤销不再需要的 Token。明文 Token 只在创建时显示一次。

连接方式见 [MCP 指南](/guide/mcp)。

## Agent

Agent 设置仍为预留入口，当前尚未开放。
