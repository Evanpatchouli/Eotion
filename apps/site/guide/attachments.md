# 图片与文件

Eotion 支持把图片和普通文件作为页面内容插入。附件上传需要联网，上传成功后附件会与正文一起显示。

## 插入图片或文件

使用工具栏或斜线菜单中的 Image / File 操作选择本地文件。图片可在页面中预览；普通文件显示为文件卡片。也可以将纯图片或纯文件拖入编辑器（取决于设备输入方式）。

## 上传状态与失败处理

上传过程中可以取消；上传失败后可以重试或移除。附件上传完成后，正文仍需完成本地保存。进入正文保存阶段后，取消操作不可用。

离线时不支持新增附件上传。请先恢复网络并确认同步状态，再在其他设备查看附件。

## 删除附件

从附件操作菜单删除图片或文件。删除会释放附件资源，无法通过撤销或回收站恢复。删除包含附件的页面同样会释放这些资源；页面本身的删除规则见[页面指南](/guide/pages)。

## 移动端说明

部分移动端原生文件选择能力仍在完善中。当前 Android 客户端已观察到图片和文件操作无法打开系统选择器的情况；如果遇到此问题，可先在 Web 或 Windows 版上传。HarmonyOS 的文件选择尚未完成设备验证。
