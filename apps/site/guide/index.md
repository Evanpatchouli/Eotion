# Eotion 用户指南

Eotion 是一个 Local-first 的文档与知识工作空间，为写作、整理与长期思考而设计。你可以在浏览器、Windows 桌面应用以及 Android / HarmonyOS 移动客户端中访问自己的页面。

## 快速开始

1. 注册账号并登录。
2. 创建一个工作区，或切换到已有工作区。
3. 在侧栏创建页面，打开页面后开始编辑。
4. 正文会自动保存在本地；顶部状态会单独显示同步进度。

## 平台说明

Web 版无需安装。Windows、Android 和 HarmonyOS 的安装包可用状态见[下载页](/download)。移动客户端仍在完善，部分原生文件选择和网络恢复行为存在限制；详情见图片与文件、同步与离线指南。
