# Architecture Decision Records (ADR)

这里记录那些**不能单纯从代码推导、但未来 Agent 需要知道其原因**的决策。

命名：`ADR-NNN-short-title.md`

模板：

```md
# ADR-NNN: 标题

## Status
Accepted

## Context
为什么需要做这个决策？有哪些约束？

## Decision
最终决定是什么？

## Consequences
带来了什么收益、代价和限制？

## Alternatives
考虑过哪些主要替代方案？为什么没有采用？
```

不要把普通实现细节或每次修 bug 都写成 ADR。
