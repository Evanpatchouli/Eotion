## Decisions

- List defaults to 25 and caps at 100.
- Query defaults to 25 and caps at 100; filters cap at 20, sorts at 10, property projection at 100 IDs.
- If `propertyIds` is supplied, output automatically includes the Title Property; the full property set remains available to server-side query and derived projection.
- Query cursors bind Workspace / Database / View identity, Database/View versions, effective Filter / Sort config hash and anchor Page version. Property projection is intentionally not part of the cursor hash.
- Relation candidate result caps at 50 and uses the existing 5000-candidate scan limit.
- Response JSON is capped at 1 MiB and uses stable MCP error categories.
