# Documentation Archive

## Purpose

This directory contains historical documents that are kept for project traceability.

Archived documents:

- record previous design decisions;
- preserve milestone acceptance history;
- help understand why current architecture and UX decisions exist.

## Usage Rules

- Historical documents are not implementation source of truth.
- New implementation decisions must follow the current documents under `docs/design/` and active execution plans.
- Do not use archived stage documents as current UI, architecture, or product requirements unless explicitly referenced.

## Current Source of Truth

- Product roadmap: `docs/exec-plans/`
- Design system and UI rules: `docs/design/`
- Current phase documents: active execution plans
