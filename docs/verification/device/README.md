# 真机验证

本目录长期保存 Eotion 各 Roadmap 阶段需要人工在真实设备上完成的验证清单与结果。

原则：

- 每个阶段使用独立文档，保留历史验证结果，不用新阶段覆盖旧阶段。
- 自动化测试结果记录在对应阶段文档；本目录只记录必须依赖真实设备、真实系统窗口或真实宿主能力的验证。
- 状态使用：
  - ✅ 已通过：已有真机证据。
  - ⬜ 待测试：能力已实现，可以人工验证。
  - ⏸ 待实现：前置能力尚未实现，不作为失败项。
  - ⚠️ 环境限制：当前测试宿主不能代表目标原生平台。
- 测试环境必须写明设备、系统、宿主方式；兼容层环境不能冒充原生平台验收。
